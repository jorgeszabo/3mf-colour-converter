3MF Colour Converter

Bambu Studio⇄PrusaSlicer

Move painted models between Bambu Studio / OrcaSlicer and PrusaSlicer without repainting them.

  • 100% local – nothing is uploaded
  • Painted colours are kept
  • Remembers your printer
My printers

Create a printer with the colour and filament type loaded in each slot (tool, MMU slot or AMS slot). It is saved in this browser and selected the next time you open the page. Files you convert then open with that printer and those filaments, and each colour in the model is matched to the nearest colour you have.

You have no printers yet – click “+ New printer”.

2Colours and extruders

        In PrusaSlicer
        
    
          
  1. Open the file as a project: File → Open project (Ctrl+O). It opens in its own tab.
    2. 
          
  2. Open the file as a project: File → Open project (Ctrl+O), or drag it into an empty PrusaSlicer window. If PrusaSlicer asks, choose “Open as project” – not “Import geometry only”.
    3. 
          
  3. PrusaSlicer switches to the printer you chose above, with one filament slot per colour and the colours set. While the model is selected it shows all green – click next to it, or open the painting tool (N), to see the colours.
    4. 
          
  4. Feel free to change the filament profile (e.g. to your own PLA) in the right panel – the colours and painting stay.
    5.

        In Bambu Studio / OrcaSlicer
        
    
          
  1. Open the file as a project: File → Open Project (Ctrl+O), or double-click it / drag it into Bambu Studio.
    2. 
          
  2. Bambu Studio switches to the printer you chose above, with one filament per colour and the colours set. The painting shows right away.
    3. 
          
  3. Feel free to change the filament type (e.g. PLA Matte) in the left panel, or sync with the AMS – the colours and painting stay.
    4.

    2.

    3. 
          
  3. The painting is on the right filament number – open the painting tool (N) to see it.

What carries over: geometry, painted colours, painted supports/seams/fuzzy skin, parts (modifiers, negative volumes, support blockers), names, placement, scaling and the extruder per object/part. Print settings (layer height, temperatures etc.) do not, because they are named differently and are printer specific.
